# Python-habit-Tracker
A menu-driven habit-tracking application developed in Python using Google Colab. The program allows users to manage habits, log daily progress, view progress reports, generate randomized motivational messages, and reset stored data.
Features
Habit Management: Add and remove habits using Python list operations and index-based deletion.
Daily Logging: Record daily habit completion and track progress over time.
Progress Reporting: Display accumulated progress for individual habits.
Motivation System: Generate randomized motivational messages to encourage consistency.
Data Reset: Clear tracked progress and restart the application.
Technical Implementation

The application uses conditional branching, loops, list manipulation, nested menus, index-based operations, and randomized outputs to manage program flow and user interaction.

Testing & Problem Solving

The program was tested across 40+ runs to identify and resolve logical errors. During testing, I discovered an issue where future-dated entries could incorrectly reset progress counts. I also independently researched Python list-removal techniques beyond the course curriculum to implement the delete-habit functionality effectively.
